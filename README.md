# Samet Gündüz - Kişisel Web Portfolyosu 👨‍💻

Merhaba! Ben Samet Gündüz. Bilgisayar Programcılığı ön lisans öğrencisiyim ve kariyerimi siber güvenlik, ağ mimarileri ve yazılım geliştirme alanlarında inşa ediyorum. 

Şu an incelediğiniz bu depo (repository), dijital kimliğimi yansıtmak amacıyla tasarladığım kişisel web sitemin kaynak kodlarını içermektedir.

## 🎯 Projenin Amacı ve Geliştirme Süreci
Bu web sitesini herhangi bir hazır şablon, framework (Bootstrap vb.) veya yapay zeka kod üreticisi **kullanmadan**, tamamen sıfırdan ve manuel olarak kodladım. Temel amacım, web teknolojilerinin (HTML5 & CSS3) çekirdek çalışma mantığını kavramak ve kendi tasarım yeteneklerimi pratik etmektir. 

## 📂 Sitede Neler Var?
Web sitem, profesyonel ve akademik gelişimimi takip edebileceğiniz statik sayfalardan oluşmaktadır:
* **Hakkımda (`hakkimda.html`):** Eğitim hayatım, hedeflerim ve siber güvenlik alanındaki kariyer planlarım hakkında detaylar.
* **İlgi Alanlarım ve Yazılar (`ozel_sayfa.html`):** Teknoloji dünyasına bakış açım ve sektörel ilgi alanlarım.
* **Sertifikalar ve Projeler:** 1 Milyon İstihdam programı gibi katıldığım eğitimler, kazandığım sertifikalar ve geliştirdiğim (Python tabanlı ağ tarayıcı vb.) projelerin sergilendiği alan.
* **Galeri (`resimler.html`):** Görsel içerikler ve CSS ile yapılandırdığım medya alanı.
* **İletişim (`iletisim.html`):** Bana ulaşabileceğiniz profesyonel iletişim kanallarım.

## 🛠️ Kullanılan Teknolojiler
* **HTML5:** Sayfa iskeleti ve semantik yapı.
* **CSS3:** Özelleştirilmiş stiller, sayfa düzeni (layout) ve duyarlı (responsive) tasarım denemeleri.
* **Özel Alan Adı (Custom Domain):** CNAME kaydı ile GitHub Pages üzerinden canlıya alınmıştır.
